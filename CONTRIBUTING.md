# Contributing

Thanks for contributing to Soroban Testbench. Keep contributions mock-first, typed, and easy for Soroban frontend developers to reason about.

## Local workflow

```bash
npm install
npm run lint
npm run typecheck
npm run test
npm run build
```

## Pull requests

- Describe the workflow or failure mode being added.
- Include tests for simulator logic, hooks, or components.
- Do not add real key handling, mainnet submission, or official Stellar/Soroban affiliation claims.
- Keep UI controls practical and accessible.
